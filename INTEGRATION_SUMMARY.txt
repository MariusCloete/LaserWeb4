WHAT TO EXPECT
================================================================================

SUCCESSFUL DETECTION (device with supported firmware):

  ========== FIRMWARE DETECTION TIMEOUT ==========
  No supported firmware detected. Closing port /dev/ttyUSB1

================================================================================
TROUBLESHOOTING
================================================================================

Docker build fails:
→ Try: docker build --no-cache -t laserweb4-debug .

Device not visible:
→ Check: ls -la /dev/ttyUSB*
→ Try: lsof /dev/ttyUSB1 (check if already in use)
→ Use: ./run-debug-docker.sh /dev/ttyUSB0 (for different port)

No logs visible:
→ Increase verbosity: VERBOSE_LEVEL=3 in docker-compose.debug.yml
→ Check: docker logs laserweb4-debug

Container exits immediately:
→ Run with: docker run -it (interactive + TTY)
→ Check error: docker logs [container_id]
